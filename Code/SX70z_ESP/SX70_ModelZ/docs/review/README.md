# 代码审查记录

本目录存放 SX70z 固件的代码审查记录。

## 约定

- 文件名：`YYYY-MM-DD-code-review.md`（同一天多轮可加后缀，如 `-2`）。
- 每次记录写明：审查基线 commit、审查范围、审查方法、严重度定义。
- 条目编号使用 `R01`、`R02`……；修复后在对应条目标记 `状态：已修复（commit）`，不要删除历史结论。
- 修改 OTA、快门/执行器时序、显示与 I2C、Web handler 前，先查看最近一次审查记录。
